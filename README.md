**「PDF ➔ JPEG」** と **「JPEG ➔ PDF」** の両方向に対応した、高速・安全なWindows向け双方向ドキュメント変換デスクトップアプリケーションです。  
外部サーバーへの通信を一切行わない**完全ローカル処理**のため、機密書類や個人情報を含むドキュメントも安心。**Velopack** によるアップデート機能を備え、常に最新の安定版をご利用いただけます。

## 📥 ダウンロードとインストール

### 1. インストーラーのダウンロード
👉 **[Releases ページ](https://github.com/pocobayashi/PdfToJpeg-Release/releases)** から最新版の **`PdfToJpeg-Setup.exe`** をダウンロードしてください。

ダウンロードした `PdfToJpeg-Setup.exe` をダブルクリックして実行します。

## ⚠️ 初回ダウンロード・起動時の警告と解除手順（重要）

本ソフトウェアはオープンソースの個人・小規模開発ツールであり、**高額な商用コード署名証明書（EVコード証明書）を取得していない（認証を受けていない）**ため、ダウンロード時や初回起動時にブラウザ、Windows SmartScreen、ウイルス対策ソフト、ファイアウォールからセキュリティ警告が表示される場合があります。

> [!TIP]
> **本アプリは完全オープンソースであり、悪意のあるプログラムは一切含まれていません。**  
> ドキュメント（PDFや画像）の変換処理は**お手元のローカルPC上でのみ完結**し、外部サーバーへファイルや個人情報を送信することは一切ありません。  
> 警告が表示された場合は、以下の該当する手順に従ってブロックを解除・許可してください。

---

### ① ブラウザでダウンロードがブロック・警告される場合

#### ■ Google Chrome の場合
1. ダウンロードトレイまたは右上のダウンロード履歴に **「一般的にダウンロードされておらず、危険を及ぼす可能性があります」** または **「安全でないダウンロードがブロックされました」** と表示されます。
2. ファイル右側のメニュー（または「^」ボタン）から **「継続」** または **「ダウンロードを保持」** を選択します。
3. 確認画面が出た場合は **「詳細表示」➔「それでも保持する」** をクリックして保存を完了してください。

#### ■ Microsoft Edge の場合
1. ダウンロード欄に **「このファイルは安全にダウンロードすることはできません」** や **「信頼できない可能性があります」** と表示されます。
2. ファイルにマウスを合わせて **「…（その他のアクション）」➔「保持」** をクリックします。
3. ダイアログ内の **「詳細表示」** をクリックし、**「保持する」** を選択してください。

---

### ② 初回起動時に「Windows によって PC が保護されました」と出る場合（SmartScreen）

Windows Defender SmartScreen により、未署名の新規実行ファイルに対して青い警告画面が表示されます。

1. 画面内の **「詳細情報」**（下線付きリンク）をクリックします。
2. 画面下部に **「実行」** ボタンが表示されます。
3. **「実行」** ボタンをクリックすると、インストーラーが起動し正常にインストールされます。  
   ※ 一度実行を許可すると、次回以降はこの警告は表示されなくなります。

---

### ③ ダブルクリックしても起動しない・無反応な場合（ファイルのブロック解除）

Windowsがインターネットからダウンロードされたファイルに付与する保護属性（Zone.Identifier）により、実行が抑制されている場合があります。

1. ダウンロードした **`PdfToJpeg-Setup.exe`** を右クリックし、**「プロパティ」** を開きます。
2. **「全般」** タブの一番下にある **「セキュリティ」** 項目を確認します。
   - `「このファイルは他のコンピューターから取得したものです。このコンピューターを保護するため、このファイルへのアクセスはブロックされる可能性があります。」`
3. **「許可する」**（または **「ブロックの解除」** / Unblock）のチェックボックスにチェックを入れます。
4. **「適用」** ➔ **「OK」** をクリックし、再度ファイルをダブルクリックして実行してください。

---

### ④ ウイルス対策ソフト（Defender / ノートン / ウイルスバスター / ZERO等）に警告・隔離された場合

知名度や流通量の少ない新しい実行ファイルに対し、ヒューリスティック（振る舞い）検知によって誤検知（False Positive）される場合があります。

1. ご利用のセキュリティソフトの通知ダイアログまたは隔離・検出履歴画面を開きます。
2. `PdfToJpeg-Setup.exe` に対し、**「復元」** または **「信頼するファイルとして許可」**、**「例外 / 除外リストに追加」** を選択してください。
3. **安全性の検証（不安な場合）**:
   - 70種類以上のアンチウイルスエンジンで一括スキャンできる無料サービス **[VirusTotal](https://www.virustotal.com/)** に `PdfToJpeg-Setup.exe` をアップロードして検査していただくことも可能です。
   - GitHub Actions の透明な CI/CD 環境でソースコードから直接ビルドされた改ざんのない公式成果物です。

---

### ⑤ 初回起動時に「Windows Defender ファイアウォール」の警告が出た場合

アプリ起動時に **「このアプリの機能のいくつかが Windows Defender ファイアウォールでブロックされています」** というダイアログが表示される場合があります。

- **理由**: 本アプリに搭載されている **差分自動更新機能（Velopack）** が、GitHub Releases API に対して「新しいバージョンが公開されているか」をHTTPS通信で確認するためにネットワークを利用するためです。
- **対処**: **「プライベート ネットワーク」** にチェックが入っていることを確認し、**「アクセスを許可する」** をクリックしてください。
- **安心ポイント**: ドキュメントの変換処理自体は完全なオフライン処理であり、ファイルの中身が外部に送信されることは絶対にありません。

## ✨ 主な特徴と双方向変換機能

### 1. 📄 PDF ➔ 🖼️ JPEG（PDF画像展開）
- **📁 ドラッグ＆ドロップで即座に展開**: PDFを放り込むだけで全ページを自動解析・サムネイル一覧表示。
- **🖼️ 3段階のDPI＆JPEG品質微調整**:
  - `150 DPI` : 一般閲覧・Web共有用（ファイルサイズ軽量）
  - `200 DPI` : 高精細ドキュメント用（バランス型）
  - `300 DPI` : 印刷・文字認識（OCR）相当の超高精細
  - JPEG圧縮率（60%〜100%）のスライダー調整に対応
- **📑 ページ番号の自動連番出力**: `ファイル名_page_001.jpg` のように自動連番で整理保存、ZIP一括保存対応。

### 2. 🖼️ JPEG ➔ 📄 PDF（画像ドキュメント結合）
- **📸 複数画像の一括ドロップ**: JPEG / PNG / WebP をまとめて投入。
- **📐 自由自在な用紙サイズとレイアウト**:
  - 用紙サイズ: 「画像サイズに合わせる (1:1 Fit)」「A4」「Letter」
  - 用紙の向き: 「自動判定 (画像比率に追従)」「縦向き (Portrait)」「横向き (Landscape)」
  - 余白: 「なし (全面フチなし)」「小 (10mm)」「標準 (20mm)」
- **🔄 ページの並び替え＆回転**: ドラッグまたは矢印ボタンで順序を自由に入れ替え、90度回転にも対応。

### 3. セキュリティ & 自動アップデート
- **🔒 100% オフライン・高セキュア処理**: すべての処理がお手元のローカルPC上で完結。社外秘文書や個人情報の漏洩リスクがありません。
- **🔄 Velopack によるスマート自動更新**: 起動時に GitHub Releases の差分（デルタ）のみを高速取得し、ワンクリックで最新版へ再起動アップデート。

## 🚀 使い方

### モード1: PDFからJPEGに変換する場合
1. アプリ上部で **「PDF ➔ JPEG」** モードを選択します（PDFファイルを直接ドロップしても自動判定されます）。
2. 出力DPIやJPEG品質を設定します。
3. **「🚀 JPEGに変換して保存」**（またはZIP一括保存）をクリックします。

### モード2: 画像からPDFに変換する場合
1. アプリ上部で **「JPEG ➔ PDF」** モードを選択します（画像ファイルを直接ドロップしても自動判定されます）。
2. 用紙サイズ（A4、画像比率など）や余白を設定し、必要に応じて順番を調整します。
3. **「📄 PDFを作成してダウンロード」** をクリックします。
